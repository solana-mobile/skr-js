# @solana-mobile/skr-domain

Resolve `.skr` domains with [`@solana/kit`](https://github.com/anza-xyz/kit). Reads mainnet only.

```sh
bun add @solana-mobile/skr-domain @solana/kit
```

The first release is in progress. Until then this package only exports the on-chain addresses of the AllDomains programs and the `.skr` top-level domain.
