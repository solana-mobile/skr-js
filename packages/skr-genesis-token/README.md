# @solana-mobile/skr-genesis-token

Verify Seeker Genesis Tokens with [`@solana/kit`](https://github.com/anza-xyz/kit). Reads mainnet only.

```sh
bun add @solana-mobile/skr-genesis-token @solana/kit
```

The first release is in progress. Until then this package only exports the on-chain addresses of the Seeker Genesis Token collection.
